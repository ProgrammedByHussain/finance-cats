# 🐾 Finance Cats

**Finance Cats** is a fun and friendly financial advisor app featuring feline finance experts ready to help you budget, invest, and manage debt—with a purr-sonal touch. Built for **GDSC Hacks 2025** by Hussain Al-Shammari, Vivek Manoj, and Sarah Mathew.

## 🧠 Meet Your Cat Advisors

- **Dr. Bartholomeow** — Credit card and investment connoisseur
- **Sir Pounce** — Master of budget optimization
- **Dr. Clawdia** — Debt management & long-term planning specialist

Each cat comes with a unique personality and financial specialty to guide you through smarter money decisions.

## ✨ Features

- 📂 Upload CSV bank statements for personalized spending breakdowns
- 💳 Get tailored credit card recommendations based on your habits
- 📈 Receive beginner-friendly investment suggestions
- 😺 Chat with animated cat advisors powered by AI and optional voice synthesis

## 🛠️ Tech Stack

- **Frontend:** React + TypeScript
- **Build Tool:** Vite
- **UI:** Tailwind CSS + shadcn/ui
- **AI Integration:** Gemini (Google AI) for financial insights
- **Voice (Optional):** ElevenLabs for realistic cat advisor voice synthesis

## 🚀 Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/viv500/finance-cats.git
   cd finance-cats
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Create a `.env` file and add your API keys (if using AI/voice features):**

   ```ini
   VITE_GEMINI_API_KEY=your_gemini_api_key
   VITE_ELEVENLABS_API_KEY=your_elevenlabs_api_key
   ```

4. **Start the development server**

   ```bash
   npm run dev
   ```
